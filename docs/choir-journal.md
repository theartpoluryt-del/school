# Хоровые группы и журнал

Группа имеет постоянный `id`, состав `studentIds` и преподавателей `assignedEmployeeIds`.
Группы по сменам не объединяются в журнале: фильтр «Группа» оставляет только её даты и учеников.
В общей таблице оценки ставятся отдельно каждому ребёнку.

Для хоровых шаблонов используются дополнительные поля:

| Поле | Значение |
| --- | --- |
| `choirLevel` | `first`, `middle` или `senior` |
| `candidateStudentIds` | Допустимый контингент возрастной ступени для распределения |
| `defaultPedHours` | Нагрузка одного занятия: 1.5 / 1.5 / 2 |
| `defaultLessonMinutes` | Фактическая длительность: 55 / 60 / 80 минут |
| `lessonsPerWeek` | 2, ориентир для ручного заполнения расписания |

Администратор распределяет состав в «Списки → Группы → Настроить». Утренний и вечерние
составы не заполняются случайным образом. Изменение постоянного состава влияет на новые
занятия, но не перезаписывает ранее выбранные подгруппы и оценки. Старые группы можно
сохранить с `isArchived: true`, не удаляя их записи и ссылки.

В занятиях `academicHours` задаёт учебную нагрузку независимо от реальных минут
`lessonMinutes`. Без этих полей сохраняется обычное правило 40 минут = 1 учебный час.
В расписании кнопка «Длительность» позволяет разделить минуты и нагрузку вручную.

Поле журнала `topic` содержит тему урока (до 2000 символов). `hoursOverride: true`
сохраняет исправленные Пед./Кц и `academicHours` только для конкретной даты при
переформировании месяца. Состав и индивидуальные оценки работают независимо от этого
исправления. Кнопка возврата часов к расписанию не удаляет тему и оценки.

Таблица «Часы по месяцам» считает Пед. + Кц по сформированным журналам за полные месяцы,
включая будущие занятия. Групповое занятие учитывается один раз. Индивидуальные занятия
разделяются по ученику, предмету, инструменту и классу. Пустой месяц показан как «—»;
прогноз на несформированные месяцы не выдаётся за проведённые уроки.

Новые поля сохраняются существующим `save_school_context` в JSONB. Отдельная миграция
таблиц или ослабление прав не требуются: преподаватель по-прежнему сохраняет только свои
занятия, администратор — общий контекст. Персональные миграции контингента не публикуются.
Платный журнал использует отдельные таблицы и правила; эти изменения его не затрагивают.
