# Отсутствия и замещения

В журнале кнопка «Отсутствие / замещение». Преподаватель оформляет свой период,
администратор — период выбранного сотрудника. Можно выбрать заменяющего или оставить
«Без замещения». Охватываются все занятия основного журнала за период, не платные.

Исходные оценки и расписание не удаляются. В период отсутствия часы исходного
преподавателя равны нулю. Заменяющий получает отдельные занятия со своим журналом
оценок и листом замещения для печати. Часы группы считаются один раз, не по числу детей.
Темы нужны только при составе от восьми учеников. Причину отсутствия видят только
исходный преподаватель и администратор.

Состав, даты, время и часы фиксируются при оформлении. Если расписание изменилось,
нужно отменить период и оформить заново. Отмена возвращает часы исходному преподавателю
и убирает замещения из итогов; записи и оценки отменённого замещения остаются в базе.
Новые занятия после переоформления начинаются без оценок. Пересечения по времени и
замещение отсутствующим преподавателем запрещены сервером.

Развёртывание: после предыдущих миграций применить `supabase/absences.sql` и выполнить
`tests/absences.sql` (тестовая транзакция откатывается). Без миграции кнопка скрыта.
Таблица закрыта RLS и прямыми правами; изменения идут через проверяющий права RPC.
Основное сохранение не может перезаписать отдельный реестр замещений.
